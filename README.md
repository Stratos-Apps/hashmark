# Hashmark 📂
Hashmark is a checksum tool to verify all your files. It can be used with a user interface or through the command line.
## Prerequisites

* A computer
* Python
* Basic CLI knowlege

## Installation and use (CLI)

### UNIX/Windows

1. Download the latest release to your `~/Downloads` folder
2. Open a Terminal and navigate to your `~/Downloads` folder
3. Execute`python3 hashmark.py hash path/to/file.zip` to verify files using SHA-256

3b. To use SHA-512: `python hashmark.py --algorithm sha512 hash path/to/file.zip`

## Installation and use (GUI)

### UNIX

1. Download the latest release to your `~/Downloads` folder
2. Open a Terminal and navigate to your `~/Downloads` folder
3. Execute `python3 hashmark_gui.py`

### Windows

Download the latest release to your `Downloads`.
Double click the file to execute it.
